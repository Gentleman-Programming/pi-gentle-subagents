# Security policy

Please report suspected vulnerabilities privately. Do not open a public issue or include exploit details in a public discussion.

## Private reporting

Use this repository's [GitHub Security Advisories](../../security/advisories/new) **Report a vulnerability** flow. Include a clear description, affected versions, reproduction steps, impact, and any suggested mitigation.

If the private reporting flow is unavailable, contact a repository maintainer through GitHub and request a private disclosure channel. Do not share sensitive details until a private channel is confirmed.

## Scope

This policy covers the package and its repository-maintained code. Reports about third-party dependencies should also be reported to the relevant upstream project.
